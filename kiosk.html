OPTIONAL HARDWARE

조명 전원 제어

키오스크와 연동해 매장 조명을 편리하게 관리하는 무선 전원 제어 솔루션입니다.

특장점

  • 고객 이용 종료 시 전등을 직접 꺼야 하는 번거로움을 최소화
  • 무선 제어로 다양한 설치 환경에 유연하게 대응
  • 매장의 스마트한 운영 분위기 조성
OPTIONAL HARDWARE

삼성 연동 복합기

키오스크와 연동해 출력과 복사를 편리하게 이용할 수 있는 매장용 복합기입니다.

주요 사양

  • CPU 1GHz 듀얼 코어 / 메모리 4GB
  • 인쇄 속도: 분당 최대 25매 (1,200 × 1,200 dpi)
  • 복사 속도: 분당 최대 25매 (600 × 600 dpi)
  • 용지: 표준 1,140매 / 최대 2,180매
OPTIONAL HARDWARE

무인 사물함

키오스크와 모바일앱에 연계되어 사물함을 판매하고, 고객에게 발급된 QR을 통해 간편하게 결제·재배정·연장할 수 있습니다.

특장점

  • 사용자가 사물함을 편리하게 관리하고 사용할 수 있는 최소 사물함
  • 키오스크와 모바일앱 연동
  • 사물함 개별 크기: 350(H) × 350(W) × 400(D)mm
OPTIONAL HARDWARE

스터디큐브 IoT
조명 및 전원 제어

좌석별 이용 상태와 연동하여 조명과 전원 소켓을 자동으로 제어하는 스마트 IoT 솔루션입니다.

특장점

  • 좌석 이용 상태에 맞춘 조명·전원 자동 제어
  • 불필요한 전력 사용을 줄이는 효율적인 매장 운영
  • 쾌적하고 스마트한 학습 공간 조성
